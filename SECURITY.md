# Security policy

MissionCut is an offline simulation tool and must not be connected to production control planes. Do not commit credentials, incident evidence, customer topology, or personal data. Uploaded graph bodies are limited to 1 MB and processed in memory; this project does not persist them.

To report a vulnerability, contact the repository owner through a private channel and include reproduction steps and impact. Do not publish sensitive details before a fix is available. No security response SLA is currently defined.
